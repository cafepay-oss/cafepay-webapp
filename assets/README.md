# Bundled assets

The build processes files in this directory.
`sass/cafepay.sass` loads the application styles.
`sass/variables.sass` contains shared style values.
`fontawesome/` contains Font Awesome Free 5.15.4 and its license notice.

Place files that need unchanged public paths in `static/`.
The `static/fonts/` directory contains Vazirmatn and its SIL Open Font License.
