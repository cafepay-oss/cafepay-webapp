# Application plugins

`nuxt.config.js` lists the plugins that run when the application starts.
`axios.js` sets up API requests and loading state.
`websocket.js` connects live order updates to the store.
`i18n.js` connects translation helpers.
`gtm.js` controls Google Tag Manager analytics.

Use the environment settings in the main README for local development.
Keep analytics and error reporting disabled when testing with local data.
